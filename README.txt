تشغيل الموقع:
1) افتح ملف index.html داخل أي متصفح حديث.
2) ضع كل الصور داخل مجلد assets بنفس الأسماء المستخدمة داخل script.js.
3) الصورة الرئيسية الحالية مرتبطة بالمسار: assets/doctor-portrait.jpg.
4) شعار/أيقونة الموقع مرتبطة بالمسار: assets/favicon.png.
5) صور الشهادات والمعرض مرتبطة داخل script.js ويمكن تغيير أسمائها أو مساراتها من هناك.
6) إذا أردت استخدام أيقونات SVG للخدمات، يمكن وضعها داخل assets/icons ثم تغيير قيمة icon داخل services في script.js إلى مسار الأيقونة مثل: assets/icons/anxiety.svg.
7) تم تعديل النصوص لتكون أكثر مهنية، وترتيب قسم عن الدكتور، وتعديل الأسئلة الشائعة، وإضافة تنبيه طبي مختصر في التذييل.
8) تم إصلاح أحجام العناوين، وتحسين عرض صور الشهادات حتى لا يتم قصها داخل البطاقات.

Run instructions:
1) Open index.html in any modern browser.
2) Keep all images inside the assets folder using the filenames referenced in script.js.
3) The hero image currently uses: assets/doctor-portrait.jpg.
4) The favicon/logo currently uses: assets/favicon.png.
5) Gallery and certificate images are controlled from script.js and can be replaced by changing filenames or paths.
6) To use SVG service icons, place them in assets/icons and set the service icon value in script.js to a path such as: assets/icons/anxiety.svg.
7) Text content was refined to be more professional, the About section was reorganized, FAQ was cleaned, and a short medical disclaimer was added to the footer.
8) Heading sizes were fixed, and certificate images now use contain mode to avoid cropping.
