تشغيل الموقع:
1) افتح ملف index.html داخل أي متصفح حديث.
2) ضع كل الصور داخل مجلد assets بنفس الأسماء المستخدمة داخل script.js.
3) الصورة الرئيسية الحالية مرتبطة بالمسار: assets/doctor-portrait.jpg.
4) شعار/أيقونة الموقع مرتبطة بالمسار: assets/favicon.png.
5) صور الشهادات والمعرض مرتبطة داخل script.js ويمكن تغيير أسمائها أو مساراتها من هناك.
6) تم تطوير التصميم إلى نسخة أكثر احترافية مع الحفاظ على نفس المعلومات ونفس مسارات الصور.
7) تم إضافة خط Cairo/Inter من Google Fonts، وإذا لم يتوفر الإنترنت سيستخدم المتصفح الخطوط الاحتياطية.
8) تم تحسين الهيدر، قسم البداية، الخدمات، الشهادات، المعرض، قسم اليوتيوب، الحجز، التواصل، والموبايل.
9) تم إضافة أزرار سريعة للموبايل: اتصال، واتساب، الخريطة.
10) تم إضافة بيانات منظمة Schema.org للعيادة لتحسين ظهور الموقع في محركات البحث.
11) إذا ظهر خطأ في مشغل يوتيوب داخل بعض المتصفحات، يبقى زر زيارة القناة يعمل بشكل طبيعي.
12) لاستبدال الملفات: انسخ index.html و styles.css و script.js و README.txt فوق الملفات القديمة، واترك مجلد assets كما هو.

Run instructions:
1) Open index.html in any modern browser.
2) Keep all images inside the assets folder using the filenames referenced in script.js.
3) The hero image uses: assets/doctor-portrait.jpg.
4) The favicon/logo uses: assets/favicon.png.
5) Gallery and certificate images are controlled from script.js.
6) The design was upgraded to a more premium medical style while preserving the same content and asset paths.
7) Cairo/Inter fonts are loaded from Google Fonts, with safe fallback fonts if unavailable.
8) Header, hero, services, certificates, gallery, YouTube, booking, contact, and mobile layout were improved.
9) A mobile quick action bar was added: Call, WhatsApp, Map.
10) Schema.org structured data was added for basic clinic SEO.
11) If the embedded YouTube player fails in some browsers, the direct YouTube channel button remains available.
12) To install: replace index.html, styles.css, script.js, and README.txt, and keep your existing assets folder unchanged.
